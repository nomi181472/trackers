# 🎬 Tracker Failure Simulator — Demo Assets Catalog

This directory contains visual demonstrations, benchmark charts, animated comparison grids, and individual tracker stress test recordings generated by the **Tracker Failure Simulator**.

All recordings run against the exact same synthetic detection streams generated by the simulator under controlled conditions (occlusions, trajectory crossovers, false alarms, missed detections, camera jitter, and bounding box noise).

## 🔬 2. Single-Tracker Stress Tests (6-Object Scenario)

Isolated stress tests of individual trackers on a standardized 6-object crossing and occlusion scenario:

| File Name | Tracker Evaluated | Algorithm Architecture | Key Observation |
|---|---|---|---|
| [`bytetrack_6obj_stress.gif`](bytetrack_6obj_stress.gif) | `bytetrack` | ByteTrack (Two-Stage BYTE Association) | Recovers low-confidence blurred tracks; highly resilient to missing detections. |
| [`botsort_6obj_stress.gif`](botsort_6obj_stress.gif) | `botsort` | BoT-SORT (ReID + Affine Camera Compensation) | Robust tracking across camera motion and dynamic crossings. |
| [`ocsort_6obj_stress.gif`](ocsort_6obj_stress.gif) | `ocsort` | OC-SORT (Observation-Centric Momentum) | Mitigates Kalman error accumulation during prolonged occlusions. |
| [`deepocsort_6obj_stress.gif`](deepocsort_6obj_stress.gif) | `deepocsort` | Deep OC-SORT (OC-SORT + Deep ReID Distance) | High IDF1 identity preservation during crowded crossovers. |
| [`embed_sort_6obj_stress.gif`](embed_sort_6obj_stress.gif) | `embed_sort` | EmbedSORT (Cosine Appearance + Kalman) | Appearance feature matching drastically reduces ID flips during path crosses. |
| [`sort_6obj_stress.gif`](sort_6obj_stress.gif) | `sort` | Classic SORT (Kalman Filter + Hungarian IoU) | Extremely lightweight baseline; prone to ID switches during full occlusions. |
| [`fasttrack_6obj_stress.gif`](fasttrack_6obj_stress.gif) | `fasttrack` | FastTrack (Velocity-Gated IoU Association) | Fast execution with velocity gating; sensitive to abrupt direction changes. |
| [`tracktrack_6obj_stress.gif`](tracktrack_6obj_stress.gif) | `tracktrack` | TrackTrack (Multi-Hypothesis Cost Gating) | Balanced multi-feature association under moderate noise. |
| [`centroid_6obj_stress.gif`](centroid_6obj_stress.gif) | `centroid` | Centroid Tracking (Euclidean Distance Matching) | Ultra-lightweight baseline; fails under close proximity and path overlap. |
| [`greedy_iou_6obj_stress.gif`](greedy_iou_6obj_stress.gif) | `greedy_iou` | Greedy IoU Tracker (Direct Overlap Matching) | Zero-Kalman baseline; drops tracks immediately when IoU drops to 0. |
